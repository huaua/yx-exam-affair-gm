## 本地配置变更

- 后端 MySQL 端口由 `3306` 调整为 `13306`，避开 Windows 保留或占用端口。
- Redis 在本地开发配置中关闭，登录令牌使用应用本地缓存。
- 前端开发代理 `/local` 指向 `http://127.0.0.1:30000`。
- 前端版本号设置为 `1.2.0`，后端版本为 `101`。
