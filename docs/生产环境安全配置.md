# 生产环境安全配置

生产环境使用独立配置启动，禁止直接复用测试配置：

```powershell
$env:GM_DB_PASSWORD = "使用密钥管理系统注入的数据库密码"
$env:GM_TOKEN_SECRET = "至少32字节的随机JWT密钥"
$env:GM_ENABLE_PPROF = "false"
$env:GM_ALLOWED_ORIGINS = "https://exam.example.edu.cn"
./gm-affair.exe ./config/config.prod.yaml
```

首次部署时将 `backend/config/config.prod.example.yaml` 复制为 `config.prod.yaml`，修改域名、数据库地址和存储配置。真实密码与 JWT 密钥只通过环境变量或密钥管理系统注入，不提交 Git。

公网入口应由 Nginx、网关或负载均衡器终止 HTTPS，并增加：

- 仅开放 443，后端 30000 端口不直接暴露；
- 单 IP 请求速率限制及登录接口更严格的限流；
- 上传、导出接口并发限制；
- 可信代理地址与 `security.trusted_proxies` 保持一致；
- 定期备份数据库并验证恢复流程；
- 日志目录限制访问权限，接入磁盘容量告警。

当前测试和生产环境均可直接使用固定验证码 `8888`，不再提供配置或环境变量开关。
